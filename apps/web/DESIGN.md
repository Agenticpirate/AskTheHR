# 0pening fused design

Linear / Vercel chrome. Apple parchment in light. SpaceX night in dark.

**Light:** canvas #f5f5f7 / #ffffff, ink #171717, hairline #ebebeb.
**Dark:** canvas #000000 / #0a0a0a, ink #ffffff, hairline #3a3a3f.
**Accent:** Vercel blue #0070f3. Error #ee0000.
**Type:** Geist + Geist Mono. Tight negative tracking on display. Uppercase 11px micro labels.
**Theme:** localStorage 0pening.theme = light | dark | system. Class dark on html.
**Space:** Generous padding. No cramped gold-editorial look.
**Chrome:** 6-8px radius, hairline rings, almost no drop shadows.
**Motion:** page enter fade+rise 400ms. Honor prefers-reduced-motion.
